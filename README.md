# lore-coloring

App de colorir com as letras do *Alphabet Lore*, para celular, tablet e desktop.

- Decisões de arquitetura e produto: [`docs/decisoes.md`](docs/decisoes.md)
- Fonte dos sprites: `assets-src/letras/` (originais, raster)
- Artefatos de runtime: `public/letras/{A..Z}/` (gerados, commitados)
